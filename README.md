# GD Web Decomp Web

A web UI for https://github.com/undefined06855/gd-web-decomp!

This code is really poor, it's pretty temporary for the most part...

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.12. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
